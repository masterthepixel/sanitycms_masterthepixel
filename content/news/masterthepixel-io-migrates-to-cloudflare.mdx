We're moving masterthepixel.io off Vercel and onto Cloudflare Workers.

The site is a pure Next.js build with no CMS backend, no server-side API routes, and no environment variables, which makes it a strong fit for a static export served entirely from Cloudflare's edge network. Static asset requests on Cloudflare Workers are free and unlimited, so hosting costs stay at zero.

The migration is happening in stages: dependency and framework upgrades first, then content and build fixes, then the static export configuration, and finally the DNS cut-over. This news post marks the point where the `/news` section went from empty to live.
